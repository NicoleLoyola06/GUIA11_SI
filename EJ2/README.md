ACTIVIDAD AUTÓNOMA 02 SEMANA N.° 11

Predicción de Ventas mediante Series Temporales con Inteligencia Artificial

Modalidad
Individual

Resultado de aprendizaje
Aplica técnicas de aprendizaje profundo y análisis de datos para construir modelos
predictivos basados en series temporales, evaluando su desempeño y utilidad para la
toma de decisiones.

1. Contextualización
Una cadena de minimarkets en Perú desea anticipar las ventas semanales para
mejorar la gestión de inventarios y evitar pérdidas económicas.
La empresa dispone de registros históricos de ventas y necesita identificar patrones
de comportamiento para predecir futuras demandas.
Como analista de Sistemas Inteligentes, debes evaluar si una técnica de series
temporales puede ayudar a resolver este problema.
